# LE2C_17_チッ_ヤ_プー_Silent_Knight

## ゲーム概要

巨大な武器を持つボス「ABADDON」と戦う、2Dボスアクションゲームです。
ジャンプやダッシュで攻撃を避けながら、剣でボスを倒してください。
ボスは残りHPによって第2形態へ移行し、攻撃パターンが変化します。

## 起動方法

`LE2C_17_チッ_ヤ_プー_Silent_Knight.exe`をダブルクリックして起動してください。

※ 実行ファイルと`Resources`フォルダーの位置関係は変更しないでください。

## 操作方法

| 操作 | キーボード・マウス | Xboxコントローラー |
| --- | --- | --- |
| 左右移動 | A / D | 方向パッド 左 / 右 |
| ジャンプ | Space | Aボタン |
| 攻撃 | マウス左クリック | Xボタン |
| ダッシュ | マウス右クリック | Bボタン |
| 決定・会話送り | Space / マウス左クリック | Aボタン |

- ジャンプは2回まで連続で使用できます。
- ダッシュ中は攻撃をすり抜けられますが、再使用までクールタイムがあります。
- コントローラーのアナログスティックは使用しません。
